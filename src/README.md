# Utility Functions Plan

이번 팀의 간단한 결과물은 유틸 함수 모음입니다.

> 실제 `.py` 파일은 팀 시작 전에 미리 만들지 않습니다. 각 담당자가 본인 Issue와 feature 브랜치에서 생성해야 개인 기여 커밋과 PR 증빙이 남습니다.

## 담당 파일

| 팀원 | 파일 | 예시 함수 |
| --- | --- | --- |
| 차씨 | `list_utils.py` | `unique_preserve_order(values)` |
| 김씨 | `math_utils.py` | `clamp(value, minimum, maximum)` |
| 송씨 | `string_utils.py` | `normalize_whitespace(text)` |

## 최소 완성 기준

- 팀원별 함수 1개 이상
- 함수별 docstring 또는 README 사용 예시
- 각자 본인 브랜치에서 PR 생성
- 리뷰 반영 커밋 1회 이상 남기기
